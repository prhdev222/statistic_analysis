# Bayesian Clinical Tutor

Source mirror of [bayesian.uraree.com](https://bayesian.uraree.com) — a Bayesian/Frequentist
clinical statistics teaching tool (2×2 diagnostic testing, causal inference/DAGs, hypothesis
testing, formula glossary, worked problems).

`index.html` is a single self-contained static page (no build step, no server-side code) — the
same file served live at bayesian.uraree.com via nginx on `pi5-hermes`.
